# LoveConnect — UI Prototype

A responsive React/Vite front-end prototype with a purple/white theme.

## Run locally
1. Install Node.js (LTS).
2. Open this folder in VS Code.
3. Run `npm install`
4. Run `npm run dev`
5. Open the local URL printed by Vite.

## Included
- Responsive desktop/mobile shell
- Discover screen with fictional sample profiles
- Local demo pass/like buttons
- Matches, Messages, Profile and Settings placeholder screens
- Privacy notice; no real accounts, location tracking, matching backend or chat
