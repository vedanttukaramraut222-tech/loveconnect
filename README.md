# LoveConnect — React Web Prototype

LoveConnect is a responsive front-end learning prototype built using React and Vite. It demonstrates a modern social discovery interface with a clean purple-and-white design.

## Live Demo

https://loveconnect-alpha.vercel.app

## Features

- Responsive desktop and mobile UI
- Discover screen with fictional sample profiles
- Local demo Like and Pass interactions
- Matches interface
- Local demo messaging interface
- Profile and Settings screens
- Browser-based demo data persistence

## Technology Stack

- React.js
- Vite
- JavaScript
- CSS
- Lucide React Icons
- LocalStorage

## Run Locally

1. Install Node.js (LTS).
2. Clone this repository.
3. Open the project folder in VS Code.
4. Install dependencies:

   npm install

5. Start the development server:

   npm run dev

6. Open the local URL displayed in the terminal.

## Project Structure

- src/App.jsx — Main application interface
- src/styles.css — Application styling
- src/main.jsx — React entry point
- src/supabase.js — Supabase client configuration
- vite.config.js — Vite configuration

## Important Notes

This is an educational front-end prototype.

- Profiles are fictional sample data.
- Messages are stored locally in the browser.
- No real user accounts or external messaging are available.
- No real matching or location tracking is performed.
- Demo interactions do not represent a production service.
